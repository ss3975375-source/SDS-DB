# Production checklist

- [ ] Configure production database and migrations.
- [ ] Configure Google Android + Web OAuth clients and release SHA-1.
- [ ] Implement server-side Google token verification.
- [ ] Implement session issuance, rotation, expiry, and revocation.
- [ ] Configure private object storage and malware scanning pipeline.
- [ ] Configure HTTPS/WSS, CORS allowlist, rate limits, and request size limits.
- [ ] Add FCM registration and generic notification payloads.
- [ ] Configure Android release signing outside the repository.
- [ ] Run Flutter analyze/test and Android debug/release builds.
- [ ] Run backend lint/typecheck/test and dependency/security scans.
- [ ] Verify no secrets or development endpoints are shipped.
